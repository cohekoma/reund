# Reund Project

A book reader with smart translation using LLM.

## Project overview

Reund is a books reader application built based on web technology that aims to provide an eBooks reader for technical books in multi majors, with engineering as first focus. The app provides an automatic and smart translation system using LLM with the goal to ensure the translated text is not just a raw text-to-text.

Besides smart translation, the project aims to provide a reader mode that is minimal, intuitive, zen-like focus with read outloud mode using a Text-to-Speech (TTS) model. I want to make a system where the Vietnamese could read the high quality and academical books in many fields without having the trouble of understanding.

### Features overview

- Smart translation: Using LLM with a set of glossary for each field and a preconfigured system prompt to avoid raw text translation.
- Reader mode: Minimal UI with all the reading-related configurations such as text fonts, background, text space, etc.
- Read out loud: A reader to read the text. The feature is expected to be able to read Vietnamese text while still ensure the pronunciation of the English text.

## Project technical stack

The project is currently in early development stage so everything is unclear and not final yet. At current state, the project is built with Python for the backend and Vue.JS for the frontend. 

The Large Language Model is not yet decided and I'm still in experimental to try out which one would provide a stable output. Text-to-Speech model is also not yet to decide.
